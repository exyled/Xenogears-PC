This folder holds replacement texture pages. Each file is named after the 16-hex key of the page it replaces and is a raw
2048 x 2048 RGBA image (4 bytes per pixel, 16 MB). The player loads them from a TextureReplace folder beside GameData.
Only three sample pages are included; the full set (about 8 GB) is made on your own machine from your own game data with
source/tools/enhance_ai.py and is not part of this repository.
